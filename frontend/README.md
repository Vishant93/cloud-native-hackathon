# EventPulse staff scanner

The scanner reads the attendee QR generated by Spring Boot, extracts the attendee UUID, and posts it to `/api/attendees/{token}/check-in`. Spring Boot validates the UUID against its attendee store and marks the attendee as checked in.

## Run locally

1. Start Spring Boot from the repository root with `.\mvnw.cmd spring-boot:run`.
2. In `frontend`, install dependencies and start Vite:

   ```powershell
   npm install
   npm run dev
   ```

3. Open the Vite URL shown in the terminal (usually `http://localhost:5173`) and allow camera access.

The Vite development server proxies `/api` requests to `http://localhost:8080`. Camera access requires HTTPS on deployed hosts; localhost is allowed by browsers.
